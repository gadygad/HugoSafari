# HugoSafari — Tanzania Tourism Website

A premium Next.js + TypeScript website showcasing Tanzania's world-renowned destinations, wildlife, and Zanzibar experiences.

## Features

- **Hero section** with animated stats and cinematic imagery
- **Marquee banners** highlighting destinations, wildlife, and traveler testimonials
- **Interactive destinations** — Olduvai Gorge, Ngorongoro, Serengeti, Zanzibar
- **Wildlife gallery** — lions, zebras, hyenas, elephants, cheetahs, flamingos
- **Zanzibar & Forodhani** — night market, dhow jumping, sunset cruises
- **Contact form** for custom safari inquiries
- **Framer Motion** animations and responsive Tailwind CSS design

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide React](https://lucide.dev/) icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```
